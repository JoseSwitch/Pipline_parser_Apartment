## 📋 Текущие файлы и задачи

Каждый файл — это отдельная задача. Работаем строго в рамках описания.

---

### 📄 `scrapers/cian_scraper.py`

**Задача:** Написать функцию `scrape_cian(url)`, которая:

1. Принимает URL страницы поиска на Cian
2. Заходит на страницу через `requests`
3. Обходит первые 5 страниц результатов
4. Собирает все ссылки на объявления (теги `<a>` с классом, содержащим `/rent/flat/` или подобным)
5. Возвращает список строк-ссылок

**Библиотеки:** `requests`, `beautifulsoup4`
**Возвращает:** `list[str]` — список URL
**Обработка ошибок:** `try/except`, если страница не загрузилась — возвращает пустой список и печатает ошибку

**Пример использования:**

```python
urls = scrape_cian("https://www.cian.ru/cat.php?deal_type=rent&engine_version=2")
print(urls)  # ['https://www.cian.ru/rent/flat/123456/', ...]
```

---

### 📄 `scrapers/avito_scraper.py`

**Задача:** Аналогично `cian_scraper.py`, но для Avito.

1. Принимает URL поиска на Avito
2. Обходит первые 5 страниц
3. Собирает ссылки на объявления
4. Возвращает список URL

**Библиотеки:** `requests`, `beautifulsoup4`
**Особенность:** Avito может блокировать запросы — добавить `User-Agent` в заголовки.

---

### 📄 `filters/title_filter.py`

**Задача:** Написать функцию `filter_by_title(urls, blacklist)`, которая:

1. Принимает список URL и список запрещенных слов (например, `["коммерция", "доля", "аренда"]`)
2. Для каждого URL заходит на страницу
3. Извлекает заголовок (тег `<h1>`)
4. Если в заголовке есть хотя бы одно слово из blacklist — пропускает этот URL
5. Возвращает отфильтрованный список URL

**Библиотеки:** `requests`, `beautifulsoup4`
**Возвращает:** `list[str]`

---

### 📄 `parsers/detail_parser.py`

**Задача:** Написать функцию `parse_details(urls)`, которая:

1. Принимает список URL объявлений
2. Для каждого URL заходит на страницу
3. Извлекает: цену (int), адрес (str), метраж (float), этаж (str), описание (str)
4. Возвращает список словарей вида:
   ```python
   {
       "url": "...",
       "price": 5000000,
       "address": "Москва, ул. Ленина, 10",
       "area": 45.5,
       "floor": "3/9",
       "description": "Светлая квартира..."
   }
   ```

**Библиотеки:** `requests`, `beautifulsoup4`
**Обработка ошибок:** Если какое-то поле не найдено — ставим `None`

---

### 📄 `database/db_manager.py`

**Задача:** Написать класс `DatabaseManager`, который:

1. Подключается к PostgreSQL (данные из `.env`)
2. Имеет метод `save_listing(data)` — сохраняет объявление в таблицу `listings`
3. Имеет метод `is_duplicate(url)` — проверяет, есть ли уже такое объявление
4. Имеет метод `get_new_listings()` — возвращает объявления, добавленные за последний час

**Библиотеки:** `psycopg2`, `python-dotenv`
**Таблица `listings`:** `id (serial)`, `url (text)`, `price (int)`, `address (text)`, `area (float)`, `floor (text)`, `description (text)`, `created_at (timestamp)`

---

### 📄 `bot/telegram_bot.py`

**Задача:** Написать простого бота, который:

1. Принимает список объявлений
2. Для каждого формирует сообщение в формате:
   ```
   🏠 Новая квартира!
   💰 Цена: 5 000 000 ₽
   📍 Адрес: Москва, ул. Ленина, 10
   📐 Метраж: 45.5 м²
   🔗 Ссылка: https://...
   ```
3. Отправляет сообщение в указанный чат

**Библиотеки:** `python-telegram-bot` или `requests` (через Telegram Bot API напрямую)
**Токен бота:** из `.env`

---

### 📄 `main.py`

**Задача:** Собрать всё вместе. Запускает по порядку:

1. `scrape_cian()` → список URL
2. `filter_by_title()` → отфильтрованные URL
3. `parse_details()` → список словарей
4. `DatabaseManager.save_listing()` → сохранение в БД
5. `telegram_bot.send()` → отправка уведомлений

**Библиотеки:** импорты из наших же файлов
**Логика:** простая, последовательная, без асинхронности и сложных конструкций
